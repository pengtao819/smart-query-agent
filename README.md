# 智能问数 Agent

用自然语言查询业务数据库：自动完成 Schema 理解、SQL 生成、安全校验、执行自修复，
并输出图表与结论。面向不会写 SQL 的业务人员。

> 状态：开发中。指标与架构图在功能完成后补齐。

## 它解决什么问题

业务方想问「上个月华东区 GMV 是多少」，传统路径是提需求给数据同学、等排期。
本系统让业务方直接提问，几秒内拿到结果，且每条回答都能追溯到具体 SQL。

难点不在「让模型写 SQL」，而在于：

- 表多、列多，schema 塞不进 prompt，需要**选表选列**
- 业务词（GMV、客单价）和物理列名对不上，需要**语义层**
- 模型会写错、会写危险 SQL，需要**护栏**和**执行反馈自修复**
- 效果好不好不能靠感觉，需要**可回归的评测集**

## 架构（规划）

```
问题 -> 意图/澄清 -> Schema 链接 -> 语义层 -> SQL 生成
     -> AST 安全校验 -> DuckDB 执行 -> 失败回灌自修复
     -> 图表选型 -> 结论摘要
```

## 快速开始

```bash
uv sync
cp .env.example .env   # 填入 LLM_API_KEY
uv run python scripts/init_db.py
```

## 目录结构

```
app/
  api/         HTTP 接口
  core/        配置、LLM 客户端、日志、异常
  db/          DuckDB 连接与元数据
  schemas/     Pydantic 模型
  services/    各环节业务逻辑
data/          业务库与评测集
scripts/       建库、评测等脚本
tests/         单测
web/           前端
```
